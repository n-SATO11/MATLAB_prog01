# MATLAB_prog01
このリポジトリには、MATLABで作成したデジタル信号処理および音響情報処理に関するプログラムをまとめています。

## 収録プログラム (随時更新します)
- `MyAudioRec.m`: 音声を録音し、WAVファイルとして保存するスクリプトです。
- `japanese_5vowels_formants_v1.m`: 音声信号のスペクトログラム表示、LP分析によるスペクトル包絡の計算、およびピーク検出によるフォルマント周波数の抽出を行うスクリプトです。

## 動作環境
以下の環境で動作確認を行っています。
- MATLAB R2024a (※ご自身のバージョンに合わせて書き換えてください)
